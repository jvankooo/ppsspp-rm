HD Rumble for PSP games

The PSP never had a vibration motor, so no PSP game asks for rumble. PPSSPP-rm, a fork of NaGaa95's PPSSPP-nx for the Nintendo Switch, works out where rumble belongs from two things: the game's sound and the game's state in memory. The demos below run the same formulas as the emulator.

Which sounds become rumble

Twelve seconds of a game's low end (everything below ~150 Hz), in 10 ms blocks. A block triggers a thump when it rises well above its own average of the last ~200 ms, so a steady drone stops counting once the average catches up. Move the sensitivity and watch the trigger line.

A God of War fight

The God of War: Chains of Olympus profile reads Kratos's health and the combo counter from memory every frame. A drop in health is a heavy rumble, harder for a bigger part of the bar; each blow that lands is a sharp tap. Nothing while paused or dead.

Strength scales everything: None 0%, Light 42%, Medium 64%, Strong 84% (default), Hard 100%. Anything that's on is lifted to at least 12% of that, since HD Rumble is barely felt below about a tenth. Overlapping effects don't add up: each band takes the strongest one.

Rumble only runs for a game with a profile in sdmc:/switch/ppsspp-nx/PSP/RUMBLE/<GAME ID>.ini. How to write one: docs/rumble.md.
